# bophacking's .dotfiles for Kali+i3wm

A light rice to keep meself productive.

## Things to Install
- i3
- stow
- picom (SKIP IF RUNNING IN VM)
- fastfetch
- feh
- autotiling

## How to Use

**Clone**
``` zsh
git clone https https://github.com/bophacking/bophackings-dotfiles
```

**Run install.sh**
```zsh
cd .dotfiles
chmod +x install.sh
./install.sh
```

**And you're bopped out!**
